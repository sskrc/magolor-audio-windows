# experiments

開発途中の試作です。記録のために残しています。パス(`D:\jsl-audio`、`D:\llvm` など)やデバイスのインスタンス ID は開発 PC 固有なので、そのままでは動きません。

| フォルダ | 内容 |
|---|---|
| `probe/` | 最初の試作。HDA / DSP のレジスタを読むだけの KMDF ドライバ |
| `wdmtest/` | ビルド環境の確認用の最小 WDM ドライバ |
| `boot/` | DSP のブートと SOF ファームウェアのロード(FW_READY 受信まで) |
| `boot2/` | ブート、IPC3 パイプライン構築、デバイス起動時に約10秒のテスト音を再生。初めて内蔵スピーカーから音が出た版 |
| `boot3/` | boot2 の派生。DAI を SSP0 にして試した比較実験 |
| `amp/` | RT1015P の SDB を Windows の GPIO API で制御する小ドライバ(`ACPI\RTL1015`) |
| `scripts/` | 上記のビルド・署名・インストール・診断用スクリプト |
